
# Sistema Web de Gestión

## 1. Descripción del proyecto

Sistema web desarrollado para una empresa de servicios que necesita
administrar sus clientes, servicios y reservas en una sola plataforma.

## 2. Objetivo

Implementar una primera versión funcional que permita organizar
la información de clientes, servicios y reservas.

## 3. Funcionalidades

### Gestión de clientes
- Registrar clientes.
- Modificar información.
- Consultar clientes.

### Gestión de servicios
- Registrar servicios.
- Establecer precio y duración.
- Consultar servicios.

### Gestión de reservas
- Registrar reservas.
- Seleccionar cliente y servicio.
- Registrar fecha y hora.
- Consultar y cancelar reservas.

## 4. Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- LocalStorage

## 8. Alcance

La primera versión se desarrolla como una aplicación frontend.
Los datos almacenados en LocalStorage permanecen en el navegador
local y no se sincronizan automáticamente entre usuarios.
